Pollsmaster

Конвертация опросов из текста в JSON-формат · v1.0.0

Что делает расширение

Pollsmaster автоматически распознаёт скопированный текст опроса с вопросами и ответами и заменяет его в буфере обмена готовым JSON-кодом. Больше не нужно вручную собирать опрос в конфиге или использовать для этого ИИ — просто скопируйте текст, вставьте результат — и данные готовы к использованию.

В десктопном приложении Google Docs расширение не работает — для конвертации используйте именно веб-версию.

Формат входящего текста

Опрос должен состоять минимум из одного вопроса и одного ответа, начинающегося с эмодзи. Каждая строка ответа начинается с иконки, за которой идёт текст ответа.

Как пользоваться

  1. Выделите в визивиге текст опроса (вопрос + ответы).
  2. Нажмите Ctrl+C (на macOS — Cmd+C).
  3. Если расширение включено — вместо текста в буфер обмена попадёт готовый JSON.
  4. Вставьте результат в конфиг (Ctrl+V / на macOS — Cmd+V).

Аналогии раскладок для macOS

Расширение работает одинаково на Windows/Linux и macOS — отличаются только клавиши-модификаторы. Ниже приведено соответствие клавиш.

Windows / Linux macOS
Ctrl (Control) Cmd / ⌘ (Command)
Alt Option / ⌥
Ctrl+C (копировать) Cmd+C / ⌘+C
Ctrl+V (вставить) Cmd+V / ⌘+V
Ctrl+Shift+… (горячая клавиша) Cmd+Shift+… / ⌘+Shift+…
Backspace / Delete Delete / ⌫

При задании горячей клавиши на macOS используйте комбинацию с Cmd (⌘), например Cmd+Shift+Y — так же, как вы привыкли использовать Ctrl+Shift+Y на Windows/Linux.

Пример

Так выглядит опрос в визивиге:

[ДОБАВИТЬ ОПРОС:
Какой язык программирования вам нравится?
🚀Python
💎Ruby
🦀Rust]

После копирования в буфер обмена попадает такой JSON:

{
  "mode": "percent",
  "answers": [
    {
      "icon": "🚀",
      "answer": "Python"
    },
    {
      "icon": "💎",
      "answer": "Ruby"
    },
    {
      "icon": "🦀",
      "answer": "Rust"
    }
  ],
  "question": "Какой язык программирования вам нравится?",
  "needLogin": true
}

Опрос с чекбоксами или опрос с возможностью выбрать несколько вариантов ответа

Если вы повторно скопируете тот же самый опрос в течение короткого времени, результат будет помечен как опрос с несколькими вариантами ответа (добавляется поле isMultipleChoice: true).

Управление расширением

Нажмите на иконку Pollsmaster на панели инструментов браузера, чтобы открыть попап с настройками:

  • Создать новый конфиг — ссылка в персефоне на страницу создания нового конфигура.
  • Включить расширение — переключатель активности. При переключении на иконке браузера на короткое время появляется бейдж ON (зелёный) или OFF (красный).
  • Показывать уведомления — включает/выключает всплывающие сигналы при конвертации опроса.
  • Горячая клавиша — кликните по полю и нажмите свободную комбинацию (например, Ctrl+?), чтобы быстро включать и выключать расширение в любой вкладке. Чтобы убрать клавишу — нажмите Backspace или Delete.

Всплывающие уведомления

При каждом действии в правом нижнем углу страницы появляется цветная плашка, которая исчезает примерно через секунду:

👍 Опрос конвертирован в JSON
✌️ Опрос помечен как множественный выбор
✅ Расширение включено
❌ Расширение выключено
Сигналы «включено/выключено» (✅/❌) показываются всегда — даже если уведомления отключены, чтобы вы не пропустили изменение состояния.
