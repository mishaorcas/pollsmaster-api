✅ Инструкция: Pollsmaster

Простой помощник для создания опросов и доработки кода из верстака. Всё делается за несколько секунд — вводите текст, копируете результат.

С чего начать

Наверху страницы два раздела — переключайтесь между ними кнопками:

  • ✅ Генератор опросов — превращает обычный текст в готовый код опроса.
  • 🚀 UGC верстак — приводит код из верстака к нужному формату.

В обоих разделах работа устроена одинаково: слева поле для ввода, справа — результат, который остаётся скопировать.

Генерация опроса в JSON для конфига

  1. Вставьте текст опроса — он должен стоять в первой строке левого поля.
  2. Если нужно разрешить выбор сразу нескольких вариантов — включите переключатель «⚡️ Опрос с чекбоксами».
  3. Готовый код появится в правом поле автоматически, как только вы вставите опрос.
  4. Нажмите «Копировать результат» и вставьте код в публикацию.

💡 Если в формате допущена ошибка (например, пропущен эмодзи или пустой вариант), под полем появится понятная подсказка — просто исправьте строку.

Обработка кода (UGC верстак)

  1. Вставьте в левое поле код, скопированный из верстака.
  2. Обработка запустится автоматически — результат появится в правом поле.
  3. При необходимости нажмите «Копировать результат» и вставьте готовый код куда нужно.

Что умеет инструмент:

  • Расставляет заголовки — добавляет ссылки-якоря на разделы из оглавления.
  • Меняет эмодзи на картинки в подборках с плюсами и минусами — ➕ и ➖ в заголовках превращаются в аккуратные бирки «плюс» и «минус».
  • Оформляет плашки «за» и «против» — плашкам присваивается нужный цвет исходя из смысла подзаголовка.
  • Оборачивает авторов в код — автоматически превращает ссылку на автора и подпись в нужную конструкцию с атрибутом prop="additional".
  • Убирает лишнее — удаляет пустые блоки и лишние пустые строки, чтобы код был аккуратным.
💡 Если результат приходит не сразу, подождите пару мгновений — обработка занимает секунды.

Полезные кнопки и клавиши

  • Вставить из буфера — переносит скопированный текст прямо в поле ввода.
  • Очистить всё — стирает содержимое полей текущего раздела.
  • Копировать результат — копирует готовый код в буфер обмена.

Горячие клавиши:

  • Ctrl + Enter — запустить обработку сейчас.
  • Esc — очистить поля активного раздела.
🖱️ Обычно запускать обработку вручную не нужно — всё происходит автоматически при вводе.
